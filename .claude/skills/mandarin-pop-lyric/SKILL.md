# 中文流行作词 Skill

## 什么时候用

- 要给 YuE2 写一首新的中文歌（2:30–3:30，女声）。
  2026-10-28 起主线是**空灵史诗 / 战斗史诗**（模式 E/F），不再是清甜日常叙事。
- 要改旧歌词：太抽象、太像文案、副歌没有钩子、唱起来倒字。
- 要审一批中文歌词：押韵、声调、重复、陈词滥调、句长。
- 要给 `zh_lyrics_gen.py` 写选题卡（angle / image bank / addressee / rhyme）。

## 先读什么

- 研究依据与目标数字：`docs/lyric_melody_zh_2026.md`
- 现有旋律工具：`tools/generation/plan_metrics.py`、`plan_shape.py`、`melody_qa.py`
- 歌词门控：`tools/generation/zh_lyric_qa.py`、`services/api/app/services/lyric_diversity.py`

## 硬规则（写之前先记住）

1. **一首歌 = 一个场景 + 一个对象 + 一个秘密。**
   对象用“你”；场景要具体到时间/地点/动作；秘密是桥段才揭示的那句话。
2. **副歌第一句就是 hook，5–8 个汉字，能脱离旋律单独说。**
   标题从 hook 或核心意象里来，3–6 个字。
3. **主歌近景，副歌远景，只推一次。**
   主歌写物件和动作；副歌把同一件事推成一句判断/愿望/反问，不要每句升维。
4. **预副歌短句排比 + 加速。**
   2–3 句，句长递减，最后一句悬住（不要落回主音/结论）。
5. **押实词，不押空词。**
   句尾优先具体名词/动词。主韵一韵到底；桥段可以换韵。
6. **声调服从旋律。**
   长音/最高音优先一声、二声、开口音（a/an/ang/ao/ai）；三声不放在最高最长音；
   虚词（的/了/着/吗/呢）放弱拍短音；一句内三声连读不超过 2 个。
7. **重复有预算。**
   Hook 全曲 2–3 次；同一句最多 2 次；末副歌换一半新词，只留 hook；
   开头/结尾不复用中间原句。
8. **桥段必须给新信息。**
   2–3 句，低音区，换韵或半换韵，句尾不要解决得太满。
9. **句长：主歌 7–11 字，副歌 5–9 字，一句一口气。**
   不要用长定语套长定语；不要为了押韵倒装成文言。
10. **具体 > 抽象。**
    每首至少 4 个可触摸的物件/动作；抽象大词（星光/远方/梦想/世界/永恒）全曲 ≤ 2 次，且不进 hook。

## 四种模式（先选模式，再写）

### A. 近景叙事流行（默认，清甜女声）

参考：汪苏泷《像晴天像雨天》、单依纯《珠玉》、裘德《春雪》。
日常物件 + 对话感 + 副歌一句钩子；BPM 85–115；2:45–3:30。用下面的 28 句配额。

### B. 悬溺型暗色氛围流行

参考：葛东琪《悬溺》：约 72 BPM，小调，词少，靠音色和空间做 hook。
规则：
- 句数 16–22，主歌 3–4 句、副歌 3–4 句，桥段可以只有 1–2 句；
- 全曲只留 2–3 个具体画面，其他靠语气和留白；
- **不要拟声词、不要哼唱**（用户 2026-10-26 明确要求）。《悬溺》的
  “Ya i ya i ya”只作为氛围参照，不进入我们的歌词；hook 必须是 3–10 个
  真词，能单独说出口；
- 词可以意识流，但**不能每句都抽象**；至少 3 个可触摸物件；
- 不要把“悬溺”写成“深渊/宿命/救赎”的同义词堆。

### C. 古风燃向

参考：指尖笑《新·与天齐》/ 倪浩毅《与天齐》：口号 hook、强重音、逆天改命。
规则：
- 句数 24–28；BPM 130–160；小调/古风调式；
- hook 是 5–8 字的**口号句**，四三或五二切分，落在强拍，能单独喊；
- 古风词可以用，但每句要有一个动作/物件（剑、灯、雪、城门、酒、马蹄），
  不要整段都是“宿命/轮回/天下/苍生”；
- 副歌可以有齐唱感；末副歌升调或加一层高八度；
- 不要写成战歌的英文史诗腔，这是中文古风，句尾要收得住。

### D. 史诗/思辨（BGM 电影感）

参考方法：邓紫棋《泡沫》《句号》《摩天动物园》《启示录》/ 2025《Bubble》《自由的你》。
**学方法，不抄符号。**
规则：
- 全曲**一个中心比喻**，必须贯穿主歌、副歌、桥段；歌名/hook 就是这个比喻。
- 三段推进：主歌写字面场景 → 桥段把比喻翻过来（反转/悖论）→ 末副歌给哲学结论。
- Hook 5–9 字，**直白、能单独说**；不要生僻词。
- 对句 + 行中停顿（4+4 / 5+5），行尾和停顿处尽量押韵；用对偶、悖论、反问制造思辨。
- 允许哲学抽象词，但每个都要落在一个具体物件/动作上；全曲抽象大词 ≤12 次，hook 里不能有。
- 电影感/BGM：弦乐、钢琴、合唱 pad、低频、慢推进；3:00–3:30；女声。
- 禁止抄“泡沫/摩天动物园/沙漠/芯片/GLORIA”这类现成符号；要自己发明一个能贯穿全曲的比喻。

### E. 空灵史诗（《诀爱》型，2026-10-28 新增）

用户 2026-10-28 判 10-26 批次为"糖水歌"，要求史诗感 + 空灵感。这一类是主攻方向。

- 20–28 句；主歌 3–5 句、副歌 3–5 句；词要少，留白要多。
- 场景必须在史诗尺度里：雪线、山口、城墙、河床、盐地、断桥、钟楼、崖边、荒原；
  **禁止**便利店、末班车、雨伞、电梯、外卖、手机、地铁等日常近景。
- 一个中心比喻贯穿全曲，歌名/hook 就是它；桥段把比喻翻过来（悖论/反问/代价）。
- 主歌低、慢、几乎耳语；预副歌短句悬住；副歌把声音放到很远，长音收句；
  末副歌才让整个乐队与合唱进来。
- 人声标签：`ethereal female vocal, floating high head voice, airy and breathy,
  distant and vast, restrained vibrato`；**不要** sweet / young / tender / intimate。
- 编曲标签：弦乐、低音大提琴 drone、钢琴、天使合唱、定音鼓、大厅混响、宽声场；
  不要 `polished modern pop` / `warm piano` / `shimmering guitars`。

### F. 战斗史诗（《新·与天齐》型，2026-10-28 新增）

- 22–30 句；BPM 130–160；小调/古风调式。
- 副歌第一句是 5–9 字口号，4+3 或 5+2 切分，落在强拍，能单独喊；
  **副歌只有第一句是 hook**，其余句子必须是新词，hook 全曲只出现 3 次。
- 每句必须有动作或物件（火把、城门、鼓、断箭、雪、铁、绳梯、号角），
  不要空喊宿命/荣耀/深渊。
- 人声标签：`powerful female vocal, heroic chest-mix belt, clear diction`；
  编曲：太鼓、二胡、笛子、古筝、弦乐、铜管、合唱、ostinato。

## 结构配额（A. 近景叙事，默认 28 句）

| 段落 | 句数 | 任务 |
|---|---:|---|
| `[Intro]` | 1 | 一句环境/动作，低、近；不要总结 |
| `[Verse 1]` | 4 | 时间+地点+一个动作+一个物件 |
| `[Pre-Chorus 1]` | 2 | 短句排比，加速，悬住 |
| `[Chorus]` | 4 | hook + 一句判断 + 一个远景 + 一句回落 |
| `[Verse 2]` | 4 | 同一场景推进：后果/转折/新动作，不是 Verse 1 改写 |
| `[Pre-Chorus 2]` | 2 | 比 Pre 1 更短/更高，最后一句是 launch |
| `[Chorus 2]` | 4 | hook 回来，另外三句至少两句新词 |
| `[Bridge]` | 2 | 新信息/反转，低音区，换韵 |
| `[Final Chorus]` | 4 | hook + 新的一半 + 最高最长的落点 |
| `[Outro]` | 1 | 回到一个具体物件/动作，低、收 |

总句数 26–30；目标 28。YuE2 的 s/line 约 5.8–9.7，28 句通常落在 2:45–3:30。

## 写作顺序（不要一上来写副歌）

1. 写一张**选题卡**：angle（一句话冲突）、image bank（5–8 个具体物件）、addressee（谁）、
   secret（桥段才说的那句）、rhyme group（主韵）、BPM/key。
2. 先写 **hook**：5–8 字，能单独说，最好带一个动作或一个物件。
3. 再写 **Verse 1**：只写近景，不解释情绪。
4. 再写 **Pre-Chorus**：把 Verse 的压力变成短句。
5. 再写 **Chorus**：hook + 一句判断 + 一个远景 + 一句回落。
6. 再写 **Verse 2 / Bridge**：推进/反转。
7. 最后写 **Final Chorus / Outro**：换一半新词，把最高音留给开口音。
8. 跑 `zh_lyric_qa.py`，按报告改，不要靠感觉。

## 输出格式

歌词文件（YuE2 吃这个）：

```
[Intro]
城市把最后一班车开走

[Verse 1]
...
```

标签必须逐字使用：`[Intro] [Verse 1] [Pre-Chorus 1] [Chorus] [Verse 2] [Pre-Chorus 2] [Chorus 2] [Bridge] [Final Chorus] [Outro]`。
不要舞台提示、不要括号、不要英文（本周中文曲）。

## 陈词滥调黑名单

这些词不是绝对禁止，但全曲合计 ≤ 2 次，且**不能进 hook**：

星光、星河、远方、梦想、光芒、光、世界、温柔、拥抱、眼泪、孤独、永恒、翅膀、繁花、
岁月、时光、心跳、命运、守护、信仰、天堂、烟火、彼岸、天涯、红尘、执念、宿命、救赎、
破晓、深渊、烈焰、誓言、荣耀、流浪、坚强、希望、未来、勇敢、奇迹、童话、宇宙。

替代方法：把词换成动作/物件/身体感受。例如：
- “我很想你” → “你留下的外套还挂在门后”
- “追逐梦想” → “把简历折成纸飞机，从六楼放下去”
- “泪流满面” → “口罩里全是咸的”
- “世界很大” → “地铁坐过三站才发现”

## 词曲咬合检查（写作时就要做）

- 句尾长音：一声/二声优先；三声尽量避免；四声可以但旋律要下行。
- 最高音：开口音 + 一声/二声；不要把三声字放在最高音。
- 连续三声：一句 ≤ 2 个。
- 虚词：不占句尾长音、不占最高音。
- 副歌 hook：至少一个开口音落在长音上。

## 最后一条

指标通过 ≠ 好听。指标只负责拦住：没有 hook、韵脚乱、三声堆叠、抽象词过多、
副歌不比主歌密/高、三段副歌不是同一个钩子。最终仍然由用户听审。
