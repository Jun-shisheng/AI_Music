# 中文流行词曲拆解（2024–2026）

> 建立于 2026-10-26。这份文档回答两个问题：
> 1. 近两年真正被听众记住的中文歌，**词**是怎么写的、**曲**是怎么走的；
> 2. 我们的 YuE2 管线要把哪些东西变成**可验收的数字**，哪些只能交给听审。

> 它不收录完整歌词（版权），只记录结构、手法、指标和可复用规则。

## 1. 这两年的中文热歌，榜单共识是什么

不同榜单口径不同（播放量 / 专业评审 / 短视频热度），但 2025 年前后有几首歌是跨榜共识：

| 歌 | 人 | 跨榜情况 | 我们能学的东西（不是抄） |
|---|---|---|---|
| 《世界赠予我的》 | 王菲 | 网易云年度 TOP1、QQ音乐/腾讯年度榜 | 慢歌、低密度、大量留白；词不解释情绪，用“世界赠予我”这种**被动句**把叙事让给听者；副歌不靠高音，靠语气和空间 |
| 《珠玉》 | 单依纯 | 腾讯音乐榜年度高分/榜首、网易云 TOP7 | 人声展示型；旋律有 R&B/Neo-soul 的转音空间；词短、意象集中，不堆形容词 |
| 《Deadman》 | 蔡徐坤 | 网易云 TOP4、QQ音乐/腾讯年度榜 | 暗色流行；低音区 Verse + 突然打开的副歌；英文 hook 与中文主歌混用（我们这周先不混） |
| 《像晴天像雨天》 | 汪苏泷 | 网易云 TOP6、腾讯年度榜 | 华语情绪流行标准件：对话式第二人称、天气/日常意象、副歌第一句就是 hook |
| 《Star Crossing Night》 | 徐明浩 / GALI | 网易云 TOP2 | 说唱/流行混合；预副歌靠节奏加密制造推力，副歌反而放松、留出 slogan |
| 《跳楼机》 | LBI 利比 | KKBOX 2025 华语年度百大冠军、短视频现象级 | 4536251 万能和弦；主歌比兴、预副歌鼓组+贝斯+歌词密集化、副歌第一句抓耳；每小节 4 拍唱约 16 字的密集韵律 |
| 《大展鸿图》 | 揽佬 | 2025 短视频现象级 | 粤剧采样 + 说唱拼贴；副歌是**口号式反复**（“大展鸿图！财源广进！”）；方言韵律和重音共振 |
| 《好风起》 | 周深 | 腾讯年度榜 | 影视感/国风流行；大线条旋律、弱起、长音收句；词偏书面但意象统一 |
| 《明日坐标》 | 林俊杰 | 腾讯年度榜 | JJ 式旋律流行：副歌音区抬升明显、句尾长音、和声进行清楚 |
| 《春雪》 | 裘德 | 网易云 TOP9 | 艺术流行；词有文学性但不晦涩；编曲留白多，靠人声表情 |
| 《命运的赛勒克》 | 刀郎 | 腾讯年度榜 | 民歌/世界音乐底色；节奏型强、重复句有仪式感；词的口语叙事和地域性 |
| 《就是哪吒》 | 唐汉霄 | QQ音乐年度十大 | 国漫/燃向；短句、强重音、口号 hook；适合“欲扬先抑”但不要写成战歌 |
| 《悬溺》 | 葛东琪 | 2020 发行、2023–2025 持续短视频翻红 | 暗色氛围流行；约 72 BPM、A 小调、Am–F–G–Em7；词很少、意识流；副歌用 “Ya i ya i ya” 无词吟唱当 hook；靠音色/空间而不是叙事 |
| 《新·与天齐》/《与天齐》 | 指尖笑 / 倪浩毅 | 2023 古风燃曲、B站循环 | 古风燃向；约 2:26；口号式 hook（“我本该命途齐天”“我命由我不由天”）；短句、强重音、逆天改命叙事；旋律跟着喊句走 |

> 结论：2024–2026 的中文热歌不是一种风格，而是**三种可辨认的写法**：
> A. 近景叙事流行（汪苏泷、单依纯、裘德）——日常细节 + 对话感 + 副歌一句钩子；
> B. 节奏驱动流行/说唱混合（《跳楼机》《Star Crossing Night》《大展鸿图》）——预副歌加密、副歌口号化；
> C. 大线条影视/国风流行（周深、林俊杰、刀郎）——长音、抬升、仪式感重复。
> 我们这周先做 A，用 B 的预副歌手法，C 只借“末副歌抬升”的结构。

## 2. 作词：从“AI 正确”到“人话 + 钩子”

### 2.1 我们上一批的病

10-22 / 10-23 的中文词，问题不是不通顺，而是**太像“励志文案”**：

- 高频抽象词：星河、远方、梦想、光、拥抱、世界、温柔、心跳、希望；
- 每句都在解释情绪，没有具体动作和物件；
- 主歌和副歌的句长、语气差不多，唱起来没有“近—远”的变化；
- 副歌 hook 是“整句抒情”，不是“可单独说出口的一句话”；
- 押韵靠句尾同韵，但韵脚字本身很空（光/方/望/亮）。

### 2.2 近两年热歌的作词规律

1. **一句一动作，少一句一形容词。**
   不说“我很想你”，说“你外套还挂在门后”。具体物件承担情绪，听众自己补完。
2. **副歌第一句就是 hook，而且能脱离旋律单独说。**
   《像晴天像雨天》的标题本身就是 hook；《跳楼机》的副歌第一句先给结论再解释。
   Hook 长度 4–10 个汉字，最好 5–8 个。
3. **主歌用“近景”，副歌用“远景”。**
   主歌：时间、地点、一个动作、一个物件（便利店、末班车、未读消息、雨伞）。
   副歌：把近景推开成一句判断/愿望/反问，但**只推一次**，不要每句都升维。
4. **预副歌靠“短句 + 重复句式”加速。**
   《跳楼机》在预副歌加鼓组/贝斯并让歌词密集化；写作上是“短句排比 + 最后一个字悬住”。
   例式：`不是…不是…是…` / `如果…如果…就…` / `一遍…一遍…`
5. **押韵要押“实词”，不要押“空词”。**
   优先让句尾落在具体名词/动词上（门、信、雨、走、等），而不是光、望、伤、方。
   华语流行最稳的韵组：`-an/ian/uan`、`-ang/iang/uang`、`-ao/iao`、`-ai/uai`、`-ei/ui`、`-ou/iu`、`-i/ü`、`-en/in/un`。
6. **声调要服从旋律，而不是反过来。**
   - 一声（高平）和二声（上扬）适合长音、高音、句尾悬停；
   - 三声（降升）不要放在最高最长的音上，唱出来会变成二声或一声；
   - 四声（下降）适合重音、落句、终止；
   - “的/了/着/吗/呢”这类虚词放在弱拍、短音上，不要占长音。
7. **副歌的高潮字用开口音。**
   长音/最高音优先落在 `a / an / ang / ao / ai` 韵母上；`i / ü / e` 收得太紧，不适合喊。
8. **重复要有预算。**
   Hook 在全曲出现 2–3 次；同一句最多唱 2 次；末副歌换一半新词，只把 hook 留回来。
   开头、结尾不要复用中间的原句（这条延续 10-15 的听审规则）。
9. **一首歌只讲一个场景、一个对象、一个秘密。**
   不要主歌写城市、副歌写宇宙、桥段写童年。对象最好用“你”，让听众代入。
10. **桥段必须给新信息。**
    不是“再唱一遍副歌前的安静”，而是揭示一个之前没说的动作/原因/反转。
    桥段 2–3 句，低音区，句尾不要押主韵，制造“离开主歌”的感觉。

### 2.2.1 用户点名的两条路线：悬溺型 / 古风燃向

这两首不能混成一种写法，它们的“成功部件”完全不同：

| | 《悬溺》型 | 《新·与天齐》型 |
|---|---|---|
| 速度/调性 | 约 72 BPM，小调，慢 | 约 140–160 BPM，小调/古风调式，快 |
| 词量 | 少，意识流，允许不叙事 | 中量，短句，叙事清楚 |
| Hook | 无词吟唱（“Ya i ya i ya”）或一个音色动机；**我们不采用无词写法** | 口号句（“我本该命途齐天”），可单独喊 |
| 情绪 | 下沉、悬置、卑微、失重 | 上升、逆反、燃、不服 |
| 编曲 | 空间大、低频心跳、副歌反而更密 | 鼓点重、弦乐/民乐齐奏、副歌齐唱 |
| 我们怎么用 | 做 1 首慢歌，检验“留白 + 无词 hook” | 做 1 首燃曲，检验“口号 hook + 强重音” |
| 不要学 | 不要为了氛围把词写成不知所云；每首仍要有一个具体场景 | 不要写成满篇“宿命/深渊/破晓/荣耀”的空喊；口号句必须落在一个动作/画面上 |

《悬溺》的关键不是“词写得玄”，而是**词退后、人声和空间上前**。如果我们要用它，
整首歌只留 2–3 个具体画面，不要塞满意象；但 **hook 仍然必须是真词**——
用户 2026-10-26 明确要求不用拟声词、不用哼唱，所以“Ya i ya i ya”这类写法
只作为参照，不进入我们的歌词。

《新·与天齐》的关键不是“古风词堆”，而是**口号句的节奏和重音**。
“我本该命途齐天”之所以能循环，是因为 7 个字、四三切分、落在强拍上；
写的时候先数拍子，再选词。

### 2.2.2 史诗/思辨模式：邓紫棋的“中心比喻”法（2026-10-26 追加）

用户当天后半段把方向收窄为：**史诗感 / BGM / 中文词要逐字推敲，最好有思辨和哲学深度，但不能失去直白**；
并点名参考邓紫棋近作的比喻方法。拆解下来，她的方法不是“堆大词”，而是四件事：

1. **一首歌只用一个中心比喻，而且这个比喻就是歌名/钩子。**
   《泡沫》= 泡沫；《句号》= 句号/蜂鸟；《摩天动物园》= 文明与兽性；《毒苹果》= 暗黑童话；
   《启示录》= 废土/乐土/芯片；2025 的《Bubble》= 一戳就破的泡泡；《自由的你》= 世界是绚烂的沙漠。
   比喻不是装饰，是整首歌的**论证对象**。
2. **直白的 hook + 哲学的反转。**
   Hook 往往是日常话（“泡沫，一触就破”“时间是个圆”），但桥段/末副歌把这句话**翻过来**：
   原来看似脆弱的东西才是真的，原来看似自由的东西才是牢。听众先听懂，再被反问。
3. **对句 + 行中停顿 + 密集押韵。**
   4+4 或 5+5 的停顿，行尾和停顿处都尽量押韵；用对偶、悖论、反问制造思辨感，
   但不用生僻词、不写成论文。
4. **具体物件托住抽象命题。**
   灯、火柴、镜子、借条、盐、空瓶、钟、圆规、门缝——每个哲学词都落在一个可触摸的东西上。
   这是“有深度但不飘”的关键。

**我们怎么做（epic 模式）：**
- 一个中心比喻，贯穿主歌/副歌/桥段；主歌写字面场景，桥段做一次反转，末副歌给哲学结论。
- Hook 5–9 字，直白、能单独说；必须和中心比喻是同一个东西。
- 允许哲学抽象词，但每个都要落在具体动作/物件上；全曲抽象大词 ≤12 次，hook 里不能有。
- **不要抄邓紫棋的具体符号**（泡沫、摩天动物园、沙漠、芯片、GLORIA）；只学方法。
- 制作上是电影感/BGM：弦乐、钢琴、合唱 pad、低频、慢推进，3:00–3:30，女声。

### 2.3 词曲咬合（tone–melody fit）

中文是有声调的语言，旋律和字调打架时，听感会“倒字”。写词阶段的硬规则：

- 句尾长音：优先一声/二声；避免三声；四声可以但要有下降旋律配合。
- 最高音：放在开口音 + 一声/二声的字上；不要放在三声字上。
- 连续三声：一句内不超过 2 个三声连读；超过就换词。
- 虚词：不放在句尾长音、不放在最高音。
- 入声/塞音结尾（粤语、部分方言）不适合长音；普通话先不管。

`zh_lyric_qa.py` 会把这些变成报告：韵脚、声调轮廓、连续三声、句尾声调、开口音比例、抽象词/陈词滥调命中。

## 3. 作曲/旋律：从“一条直线”到“有形状”

### 3.1 我们的测量基线

已有工具测过：我们 10-15 批次的副歌/主歌吐词密度比只有 **1.14**，参考曲行为是 **1.5–2.5×**；
副歌音区只比主歌高 **+2.7 半音**；三段副歌的钩子相似度 **0.902**，参考曲中位 **0.978**。
听感翻译就是“从头到尾一个节奏、副歌不像副歌”。

### 3.2 中文流行的旋律规律

1. **动机先于旋律。**
   副歌 hook 是一个 2–4 个音的核心动机，重复/模进/节奏变形；不要每句都写新旋律。
   真实副歌是“同一个钩子又来了”，不是“和弦一样、旋律每次换说法”。
2. **主歌窄、副歌宽。**
   主歌音域 5–8 个半音，级进为主，音区偏低、靠近说话；
   副歌音域 8–14 个半音，允许跳进，音区比主歌高 2–5 个半音。
3. **预副歌是“加速带”，不是“小副歌”。**
   音高不一定最高，但节奏要加密、句长要变短、最后一个音要悬住（不要落回主音）。
4. **副歌第一句就要给最高点或最长音。**
   不要等到第三句才到高潮；听众的注意力在前 10 秒。
5. **末副歌抬升。**
   升 2 个半音（全音）或升八度，或者把最后一句的长音再拉长；这是中文流行最稳的“情绪加码”。
6. **句尾落和弦音。**
   主歌句尾可以停在 2 度/5 度（未解决），副歌句尾落到主音/三音（解决）。
7. **留白是设计。**
   主歌 rest share 15–35%，副歌 5–18%；副歌不是“字越密越好”，而是“密—停—密”的呼吸。
8. **4536251 / 6415 / 1564 可用，但不要整首不变。**
   主歌用一个循环，副歌换到关系小调/四级，桥段再换；和弦是骨架，hook 是脸。
9. **音域别超过 1.5 个八度。**
   清甜女声的舒适区大约 A3–D5；副歌最高音不要连续多句停在同一个高音，否则会“喊”。
10. **节奏要有记忆点。**
    副歌 hook 至少有一个切分/附点/短-短-长，不要全是平均八分音符。

### 3.3 目标数字（先作为临时标尺，等中文参考曲剖面上线后替换）

| 指标 | 主歌 | 副歌 | 说明 |
|---|---|---|---|
| 吐词密度（起音/秒） | 1.0–1.8 | 2.0–4.0 | 副歌/主歌 ≥ 1.5 |
| 音区中心 | 低 | 比主歌高 2–5 半音 | 末副歌再高 0–2 |
| 音域 | 5–9 半音 | 8–14 半音 | 全曲 ≤ 19 半音 |
| rest share | 15–35% | 5–18% | 主歌留白，副歌收紧 |
| 级进比例 | ≥ 55% | ≥ 45% | **仅诊断**：用户要的是音高有变化，不是每句级进；低分不否决 |
| 同音重复比例 | ≤ 30% | ≤ 25% | 避免“念经” |
| 钩子相似度（三段副歌） | — | ≥ 0.85 | 计划层用 `--hook chorus` 保证 |
| 高潮位置 | — | 0.55–1.00 | 最高音落在后半段；末副歌最高音落在最后一小节也可以 |

这些数字由 `melody_qa.py` 从 YuE2 的 ABC 计划直接算，不需要渲染。

```
选题/角度
  -> zh_lyrics_gen.py（DeepSeek，按 §2 的规则写词 + 本地门控）
  -> zh_lyric_qa.py（韵脚/声调/陈词/密度/hook）
  -> YuE2 生成 2 个候选（原生 48 kHz）
  -> plan_shape.py（hook chorus + split chorus + thin verse）
  -> melody_qa.py（音域/密度/级进/钩子/高潮位置）
  -> arc_qa + diction_qa（听感代理）
  -> 人耳听审（最终标准）
```

**不做什么：**
- 不做 SVC / 换声（10-22 已证明高音会崩）；
- 不做 EQ/降噪/压缩/限幅（零后处理原则）；
- 不用旧 batch 的歌词和 brief（本周全部重写）；
- 不把“指标通过”当成“好听”，指标只负责拦住坏文件和不合格的结构。
