# 你的反馈 → 我改工作流的地方（2026-10-28）

> 这份文档回答一个问题：**你听完之后说什么，能让我下一轮真正改对地方。**
> 每条反馈最好带上「曲名 + 时间点 + 一句话」，例如：
> `钉子 1:12 人声太飘，像隔着一层布`。
> 下面每一类都对应到具体的工具、参数或标签，不是"再调调看"。

---

## 1. 先分清：哪些事我能量化，哪些只能靠你

**我已经会自动量的**（每批出片就会跑，你不用报）：

- 结构：`arc_qa` —— 是否 build-up（欲扬先抑）、高潮在几分之几、起伏多少 dB；
- 咬字：`diction_qa` —— whisper 对参考歌词的覆盖，低于 0.75 会标 `weak_lyrics`；
- 旋律：`melody_qa` —— 副歌/主歌吐词密度比、副歌音区抬升、三段钩子相似度；
- 混音：`style_qa` —— 调式、速度、立体声宽度、2–6k 存在感、sub、质心；
- 时长、峰值、削波、静音。

**只能靠你听的**（也是我最需要你给反馈的）：

1. 音色对不对（清甜 / 御姐 / 空灵 / 太电子）；
2. 旋律记不记得住、像不像"歌"；
3. 情绪真不真（有没有硬喊、有没有塑料感）；
4. 词听起来是不是人话、有没有倒字；
5. 和参考曲差在哪一口气。

所以**不要说"不好听"**——那会让我只能瞎猜。用下面任意一类说，我就能落到具体改动。

| 「太长 / 太短」 | 调歌词句数配额、`--max-plan-seconds`、`--intro-bars`；长度门控会拦 | `run_epic_batch_*.py`、`MODE_BRIEFS` 的 `total` |

## 3. 三种"一句话"就能让我开工的反馈

1. **选方向**：`哲思御姐继续` / `空灵多来点` / `战斗再猛一点` / `BGM 要长的`。
2. **点问题**：`钉子 1:12 人声太飘`、`举火的人副歌不够燃`、`灯亮着太慢`。
3. **给参考**：`像诀爱那种空`、`像新与天齐那种喊`、`像自由的你那种词`。

这三类都不需要你懂音乐制作；我负责把它们翻译成标签、seed、计划编辑和门限。
